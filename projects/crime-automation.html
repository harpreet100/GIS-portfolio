1. Operational Problem

Analyzing multi-category crime incident datasets (burglary, assault, and arson) in ArcGIS Pro by hand requires running identical geoprocessing tools across multiple feature classes, manually deleting intermediate join artifacts, and re-sorting summary tables whenever source records update. Any missed step introduces schema inconsistencies into the project file geodatabase (FGDB).

2. Data & Spatial Pipeline

  1. Workspace Configuration: Set arcpy.env.workspace to the target FGDB and enable overwriteOutput = True for repeatable execution.
  2. Spatial Join Execution: Join point incident layers (burglary, assault, arson) against precinct polygons or landmark proximity zones using arcpy.analysis.SpatialJoin.
  3. Aggregation & Ranking: Run arcpy.analysis.Statistics to aggregate incident counts by precinct, then sort descending with arcpy.management.Sort.
  4. Schema Hygiene & Cleanup: Drop redundant join fields via DeleteField, remove intermediate feature classes, and enumerate final FGDB contents for verification.

3. Code & Architecture

Representative ArcPy pipeline pattern demonstrating batch spatial joins, summary statistics, descending sort, and geodatabase cleanup:

crime_pipeline.py · Python / ArcPy 
import arcpy

arcpy.env.workspace = r"C:\GIS\Projects\CrimeAnalysis.gdb"
arcpy.env.overwriteOutput = True

precincts = "Police_Precincts"
incident_layers = ["Burglary_Incidents", "Assault_Incidents", "Arson_Incidents"]
intermediate_outputs = []

for layer in incident_layers:
    join_fc = f"{layer}_PrecinctJoin"
    stats_tbl = f"{layer}_Summary"
    sorted_tbl = f"{layer}_Ranked"

    # 1. Spatial join incidents to precinct boundaries
    arcpy.analysis.SpatialJoin(
        target_features=layer,
        join_features=precincts,
        out_feature_class=join_fc,
        join_operation="JOIN_ONE_TO_ONE",
        match_option="WITHIN"
    )
    intermediate_outputs.append(join_fc)

    # 2. Summarize incident counts per precinct
    arcpy.analysis.Statistics(
        in_table=join_fc,
        out_table=stats_tbl,
        statistics_fields=[["OBJECTID", "COUNT"]],
        case_field=["PRECINCT_ID"]
    )
    intermediate_outputs.append(stats_tbl)

    # 3. Sort descending by incident count
    arcpy.management.Sort(
        in_dataset=stats_tbl,
        out_dataset=sorted_tbl,
        sort_field=[["FREQUENCY", "DESCENDING"]]
    )

# 4. Remove intermediate datasets to keep FGDB clean
for temp_ds in intermediate_outputs:
    if arcpy.Exists(temp_ds):
        arcpy.management.Delete(temp_ds)

print("Deliverable tables:", arcpy.ListTables("*_Ranked"))

4. Measurable Result

  • Replaced multi-step manual geoprocessing with a single repeatable Python execution across all three incident categories.
  • Eliminated stray intermediate join feature classes from the production file geodatabase via automated post-processing cleanup.
  • Standardized descending-ranked summary tables for consistent cartographic symbology and reporting.
