Project Overview

ArcGIS Pro Python ArcPy GTFS APIs File Geodatabase

Problem

Transit systems generate vast amounts of structured data through GTFS (General Transit Feed Specification). The challenge is efficiently retrieving, processing, and converting both static route data and dynamic real-time vehicle locations into actionable GIS feature classes for visualization and analysis.

Data

This project utilized Calgary Open Data, specifically the Calgary Transit static GTFS schedules and the GTFS-Realtime feeds containing live vehicle information.

Method & Workflow

I developed a programmed workflow to automate the extraction and conversion of tabular and JSON-based transit data into a spatial format within a File Geodatabase.

Results & Technical Details

The resulting automation successfully retrieved live vehicle information, processed transit routes/trips, and mapped the data directly into a structured geodatabase. By automating data processing via Python and ArcPy, the workflow eliminated the need for manual CSV conversions and manual feature plotting.

What I Learned

Working with live API endpoints and GTFS structures reinforced my understanding of bridging software development with GIS. I gained practical experience writing ArcPy scripts that interface directly with dynamic external data sources to update geographic feature classes dynamically.
