An evolving GIS case study using transportation data, ArcGIS, Python, and GTFS concepts.

Overview

This project explores how transit information can be prepared and examined in a GIS environment using ArcGIS and Python concepts. The case study is designed to connect transportation datasets with spatial analysis and clear map communication.
